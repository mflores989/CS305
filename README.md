# CS305
For my CS 305 project, I worked as a developer for Global Rain to improve the security of Artemis Financial's software application. Artemis Financial is a consulting company that provides personalized financial plans involving savings, retirement, investments, and insurance. The company wanted to modernize its application by implementing secure communications and a checksum verification process to help protect sensitive financial information. To address these requirements, I implemented SHA-256 hashing to generate a checksum, configured HTTPS using a self-signed certificate created with Java Keytool, and recommended AES-256-GCM for protecting confidential data through encryption. One aspect I handled well was identifying security vulnerabilities through OWASP Dependency-Check and recognizing the difference between vulnerabilities in existing dependencies and potential vulnerabilities introduced by my changes. The most challenging part was configuring and troubleshooting the dependency-check tool, particularly updating the Maven plugin and resolving configuration errors. However, this process helped me better understand how security testing tools identify vulnerabilities and why maintaining updated software dependencies is important. Secure coding is essential because it protects sensitive information, reduces the risk of unauthorized access, and helps maintain customer trust and a company's reputation.

I increased the application's layers of security by implementing cryptographic hashing, configuring HTTPS, and reviewing the application for potential security weaknesses. After refactoring the code, I performed functional testing by running the application in Eclipse and verifying that the HTTPS endpoint successfully displayed the expected SHA-256 checksum without errors. I also completed a secondary dependency scan to evaluate the application's libraries and identify remaining vulnerabilities. Although the scan completed successfully, it revealed vulnerabilities associated with outdated dependencies that would require further remediation before production deployment. In future projects, I would continue using OWASP Dependency-Check, manual code reviews, vulnerability assessment frameworks, and current security recommendations to prioritize risks and select appropriate mitigation strategies. Tools such as Eclipse, Maven, Java Keytool, and OWASP Dependency-Check were especially valuable throughout this assignment and will be useful in future software development projects. I could also present this project to potential employers as an example of my ability to implement secure communication protocols, apply cryptographic techniques, troubleshoot development issues, conduct vulnerability assessments, and document security improvements. Overall, this project strengthened my understanding of how secure coding practices contribute to reliable software and help organizations protect their information and operations.
